Crop Yield Calculator 

A beginner Python project designed to calculate crop yield per hectare from harvested crop weight and cultivated land area.

Objective

To build a simple tool that helps users calculate crop yield and understand a basic agricultural measurement.

Planned Features

- Accept harvested crop weight in kilograms.
- Accept cultivated land area in hectares.
- Calculate yield in kilograms per hectare.
- Display the result clearly.
- Validate inputs to prevent invalid calculations.

Formula

Crop yield (kg/ha) = Harvested weight (kg) ÷ Cultivated area (ha)

Example:

- Harvested weight: 2,400 kg
- Cultivated area: 0.8 hectares
- Calculated yield: 3,000 kg/ha

Technology

- Python

Learning Goals

- Variables and data types
- User input and output
- Arithmetic operations
- Functions and input validation
